# 知识沉淀（可选）

## 触发

全部 Task 完成后，由编排层调用。**先询问用户**，不自动写入。

## 询问内容

> 本次任务已完成。是否将以下概要沉淀到个人 evolution log？
> （概要列出：踩坑、关键决策、可复用模式）
> 团队知识库合并为可选项，需要你明确同意。

## 沉淀格式（个人 evolution log）

### [日期] [需求名称]
- **模式**：简单/完整
- **踩坑**：现象 → 根因 → 解决
- **决策回放**：事后看是否正确，如果重来会怎么选
- **可复用**：代码片段 / 配置 / 流程 / Skill 改进点

## 团队知识库合并

仅当用户明确同意时执行。合并内容去标识化，不包含个人路径、密钥、内部敏感信息。
